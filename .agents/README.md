# Agent Governance

This directory contains the portfolio repository's durable agent governance, adapted from the Sensio workflow for a single static Next.js codebase.

- `codebases.conf` — codebase registry.
- `scripts/codebase-policy.sh` — architecture/testing policy checks.
- `scripts/engineering-guard.sh` — fast/full/release quality entry point.
- `scripts/maintainability.py` — closure-only maintainability ratchet.
- `maintainability/portfolio.json` — accepted maintainability baseline.
- `plans/` — substantial active implementation plans only.
- `knowledge/` and `memory/` — durable reusable engineering knowledge/outcomes only.

Current operating policy lives in root `AGENTS.md`.
