# Faris Munir Mahdi - Portfolio

This is the personal portfolio website of **Faris Munir Mahdi**, a Software Engineer specializing in Backend, Cloud, and IoT.

## Built With

- [Next.js](https://nextjs.org) - React Framework
- [Once UI](https://once-ui.com) - Design System

## Overview

This project showcases my professional work, technical skills, and writings. It is designed to be clean, fast, and accessible.

## Development

To run the project locally:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
