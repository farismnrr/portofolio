# Documentation

This repository is a single static Vue 3 + Vite portfolio.

- [ARCHITECTURE.md](./ARCHITECTURE.md) — static prerender and production model.
- [../AGENTS.md](../AGENTS.md) — engineering workflow, policy, and guard lifecycle.

A successful production build creates `dist/index.html`, `dist/404.html`, `dist/robots.txt`, `dist/sitemap.xml`, plus static HTML for every project/blog route. No production server runtime is required.
