# Technology marks

- LangGraph, Tauri, and Zigbee2MQTT use their corresponding `simple-icons` v16.35.0 exports
  (`siLanggraph`, `siTauri`, and `siZigbee2mqtt`) from `frontend/node_modules/simple-icons`.
- TimescaleDB, Docker, and the other existing Simple Icons mappings remain unchanged.
- Mosquitto uses its official Eclipse Mosquitto logo, retrieved through the GitHub contents API from
  [logo/mosquitto-logo-only.svg](https://github.com/eclipse-mosquitto/mosquitto/blob/master/logo/mosquitto-logo-only.svg).
- OpenAI Codex and OAuth 2.1 use path data from Tabler Icons outline SVGs, licensed under MIT, sourced from
  `frontend/node_modules/@tabler/icons/icons/outline/brand-openai.svg` and
  `frontend/node_modules/@tabler/icons/icons/outline/brand-oauth.svg`.
- Voyage AI Embeddings, Docker Compose, BullMQ, and Tokio render without a brand mark; their former
  custom glyphs were not verified brand assets.
- Other official asset paths supplied for possible later local use: [Zigbee2MQTT logo](https://github.com/Koenkk/zigbee2mqtt/blob/master/images/logo_vector.svg) and
  [Docker Compose logo](https://github.com/docker/compose/blob/main/logo.png).
  The Mosquitto SVG was retrieved from the official GitHub contents API. Retrieval of the other listed assets was not attempted for this task.
