Designing and implementing HTTP APIs and web services across TypeScript/JavaScript, Rust, and Go stacks, including authentication, validation, persistence, asynchronous workflows, service integration, and production observability. Portfolio examples include Express in Parentify, NestJS across Sensio products, and Axum in the current Sensio IoT rewrite.

Production NestJS work also uses its class-based module, controller, and service structure with dependency injection to keep application responsibilities separated. I treat that as practical object-oriented application design, while the Rust services use different composition and domain-boundary patterns rather than forcing the same paradigm onto every stack.
