Designing and implementing HTTP APIs and web services across TypeScript/JavaScript, Rust, and Go stacks. The work covers authentication, validation, persistence, asynchronous workflows, service integration, and production observability. Portfolio examples include Express in Parentify, NestJS across Sensio products, and Axum in the current Sensio IoT rewrite.

Production NestJS work uses class-based modules, controllers, and services with dependency injection to separate application responsibilities. I treat that as practical object-oriented application design. The Rust services use composition and domain boundaries that fit that ecosystem instead of copying the same structure across every stack.
