## Overview

A secure PDF viewer application designed for document management with end-to-end encryption. Built with Next.js and integrated with multi-tenant authentication, this application provides a safe environment for viewing and managing sensitive PDF documents.

## Key Features

- **Secure Encryption**: AES-256-GCM encryption for all stored PDF files
- **Multi-Format Support**: PDF, JPEG, PNG, WebP, and BMP file viewing
- **PDF Rendering**: High-quality PDF rendering using pdf.js and Canvas
- **Multi-Tenant Auth**: Integrated SSO with role-based access control
- **Database Flexibility**: Support for both PostgreSQL and SQLite via Drizzle ORM
- **Secure Storage**: Encrypted file storage with database-backed metadata

## Tech Stack

### Frontend
- **Framework**: Next.js 16.1.1
- **UI Library**: React 19.2.3
- **State Management**: Zustand 5.0.9
- **Styling**: Tailwind CSS 4
- **Components**: Radix UI primitives

### Backend and Data
- **Database**: PostgreSQL / SQLite
- **ORM**: Drizzle ORM 0.39.1

### Security
- **Encryption**: AES-256-GCM for file encryption
- **Authentication**: JWT tokens (via Multi-Tenant User Management Service)

### Developer Experience
- **Language**: TypeScript 5
- **Testing**: Jest 30.2.0 with React Testing Library
- **Linting**: ESLint 9
- **Build Tools**: tsx for TypeScript execution
- **Containerization**: Docker with multi-arch support

## Architecture

### Authentication Integration

This application integrates with a custom [Multi-Tenant User Management Service](/work/multitenant-user-management) for:
- Single Sign-On (SSO) authentication
- Multi-tenant user isolation
- Role-based access control
- Secure session management

### File Processing Pipeline

1. **Upload**: Files are validated and encrypted using AES-256-GCM
2. **Storage**: Encrypted files stored with metadata in database
3. **Retrieval**: Files decrypted on-the-fly for authorized users
4. **Rendering**: PDF.js renders documents in browser canvas

## Supported File Types

- **PDF**: `.pdf` (application/pdf)
- **JPEG**: `.jpg`, `.jpeg` (image/jpeg)
- **PNG**: `.png` (image/png)
- **WebP**: `.webp` (image/webp)
- **BMP**: `.bmp` (image/bmp)

## Deployment
