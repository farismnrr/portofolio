## Overview

A modern, responsive portfolio website designed to showcase professional projects, technical skills, and blog content. Built with Next.js and Once UI design system, this portfolio emphasizes clean aesthetics, performance, and user experience.

## Solution

This portfolio delivers a structured, fast, and visually consistent platform to present professional work, technical writing, and credentials in one place, making it easy for recruiters and collaborators to evaluate projects and experience quickly.

## Key Features

- **Project Showcase**: Dedicated pages for each project with detailed descriptions, tech stacks, and live demos
- **Blog Integration**: MDX-based blog system for technical writing and documentation
- **Responsive Design**: Optimized for all devices with mobile-first approach
- **Dark Mode**: Theme switching with system preference detection
- **SEO Optimized**: Proper meta tags, Open Graph, and sitemap generation
- **Performance**: Static site generation with Next.js for fast load times

## Tech Stack

### Frontend
- **Framework**: Next.js 16.1.1 with App Router
- **UI Library**: React 19.2.3
- **Design System**: Once UI (customizable component library)
- **Styling**: CSS Modules with design tokens
- **Icons**: Custom icon system with fallbacks

### Content Management
- **Blog**: MDX (Markdown + JSX) for rich content
- **Metadata**: Frontmatter-based project and blog metadata
- **Image Optimization**: Next.js Image component with lazy loading

### Developer Experience
- **Language**: TypeScript
- **Build Tool**: Turbopack (Next.js 16)
- **Linting**: ESLint with Next.js config
- **Version Control**: Git with conventional commits

## Design Philosophy

### Clean and Professional
- Minimalist design with focus on content
- Consistent typography and spacing
- High contrast for readability
- Smooth animations and transitions

### Customizable
- Design tokens for easy theming
- Modular component architecture
- Configurable content structure
- Flexible layout system

### Performance-First
- Static site generation where possible
- Optimized images and assets
- Minimal JavaScript bundle
- Fast page transitions

## Project Structure

The portfolio is organized into clear sections:
- **Home**: Introduction and featured projects
- **Projects**: Project showcase with filtering
- **Blog**: Technical articles and documentation
- **About**: Professional background and skills
- **Gallery**: Visual portfolio (optional)
